# HudFabric 1.0.9 — release notes

HudFabric 1.0.9 fixes effects HUD crashes caused by invalid characters in modded status-effect icon paths. The invalid icon is skipped while the effect name and duration remain visible. The fix is included in all nine builds for Minecraft 1.21–1.21.11 and 26.1–26.3.
