HudFabric

HudFabric is a clean, client-side HUD editor for Minecraft Fabric. Move, scale, and style useful HUD modules directly in-game—no server installation required.

Source code · Releases · Report an issue

Modules

  • Custom scoreboard with server formatting support
  • FPS and ping display
  • Coordinates and biome
  • Potion effects with icons and accurate remaining time
  • Armor and tool durability in panel or vanilla hotbar style
  • Left/right CPS counter
  • Jump Reset Indicator for PvP timing practice
  • Configurable crosshair, Crosshair Indicator, and block outline

Highlights in 1.0.8

  • Share HUD settings with a privacy-safe copy/paste code; server profiles and addresses stay local
  • Move the pause-menu HUD Editor button with its pencil control or configurable Right Alt key
  • Use the vanilla hotbar slot sprite for independent armor widgets, including resource-pack slot textures
  • Keep module reset controls and the familiar compact editor layout
  • Use a redesigned personal note board with a Minecraft-style wood frame, cork backing, pinned paper, and ruled writing lines
  • Drag HUD modules on Minecraft 26.3 with SDL3-correct left-button handling; the 26.3 client regression test verifies module movement

Compatibility

Nine grouped builds cover Minecraft 1.21 through 1.21.11 and 26.1 through 26.3. Match the downloaded JAR to the Minecraft version range shown in its filename.

Requires Fabric Loader and Fabric API. Use Java 21 for 1.21.11 and Java 25 for 26.x. Mod Menu is optional.

The note board is local to your client and is not shared with other players.
