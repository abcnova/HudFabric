# HudFabric 1.0.6

This compatibility and reliability update adds Minecraft 26.3 and makes the
Jump Reset Indicator much more precise.

## Highlights

- Minecraft 26.3 support
- Six dedicated builds from 1.21.11 through 26.3
- Real jump-event detection instead of key polling
- Combat-only Jump Reset Indicator activation
- Early, perfect, late, and missed timing feedback
- Updated translations and consistent module naming
- Dependency and performance cleanup across all supported versions

Existing HudFabric settings remain compatible and are migrated automatically.
