# HudFabric 1.0.7

This update repairs the HUD editor and makes settings easier to manage across the supported Minecraft versions.

- Open the HUD canvas directly from Mod Menu, the pause menu, or the keybind.
- Fix module dragging that failed in 1.0.6 on Minecraft 26.3 by tracking held mouse movement; verified with a 26.3 client game test.
- Keep saved HUD elements and separate armor slots inside the visible canvas when the window size changes.
- Show the installed HudFabric version and project icon in the settings header.
- Keep the familiar 1.0.6 settings layout. All eight modules fit without scrolling at the tested compact window size; scrolling appears when the available height is smaller. Long labels stay inside their buttons, and narrow screens use a separate color page.
- Show the full Jump Reset Indicator heading above its clearly separated Background and Text color controls.
- Reset one module, the crosshair, or extra settings to their first-install defaults; reset everything from the module overview. Changes are saved to the active server profile.
- Remove unsupported server glyphs and trailing symbols from custom scoreboard titles while keeping styled text.
- Preserve potion effects when entering a world.

Dedicated JARs target Minecraft 1.21.11, 26.1, 26.1.1, 26.1.2, 26.2, and 26.3. Existing settings are retained unless a reset button is used.
