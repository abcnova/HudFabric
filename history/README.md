# HudFabric release history

This directory preserves the available HudFabric 1.0.0–1.0.3 releases by
Minecraft version. Each entry contains:

- a privacy-safe archival JAR,
- resources extracted from that JAR, and
- Java source reconstructed from the compiled classes with CFR 0.152.

The original source trees for these releases were not available. Reconstructed
source can differ from the code that was originally written and is provided for
reference and maintenance. Historical package names were replaced with
`dev.abc_nova.hudfab` before publication so that no private identity is exposed.

Current, maintained 1.0.4 source lives under `versions/`.
